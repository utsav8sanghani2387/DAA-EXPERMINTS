In this practical, we learned how to solve the Coin Change problem using dynamic programming. We understood how using a dynamic programming table to store the minimum number of coins needed for smaller sub-amounts helps us determine the optimal solution for the target amount efficiently without redundant computations.

Time and Space Complexity:
- Time Complexity: O(n * amount) where n is the number of coin denominations and amount is the target amount.
- Space Complexity: O(amount) for storing the dynamic programming array.
