In this practical, we learned how to perform graph traversals using Depth First Search (DFS) and Breadth First Search (BFS) on a graph represented by an adjacency matrix. We understood how BFS traverses vertices level by level using a queue (FIFO), while DFS traverses as deep as possible along each branch before backtracking using recursion (call stack).

Time and Space Complexity:
1. Breadth First Search (BFS):
   - Time Complexity: O(V^2) where V is the number of vertices (using an adjacency matrix).
   - Space Complexity: O(V) for the queue and visited array.
2. Depth First Search (DFS):
   - Time Complexity: O(V^2) where V is the number of vertices (using an adjacency matrix).
   - Space Complexity: O(V) for the recursion stack and visited array.
