In this practical, we learned about five sorting algorithms: Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, and Quick Sort. We saw how simple sorting methods work by comparing adjacent or minimum elements, while divide and conquer algorithms like Merge Sort and Quick Sort split the array into smaller parts to sort faster.

Time and Space Complexity:
1. Bubble Sort: Time complexity is O(n^2) worst case and space complexity is O(1).
2. Selection Sort: Time complexity is O(n^2) worst case and space complexity is O(1).
3. Insertion Sort: Time complexity is O(n^2) worst case and space complexity is O(1).
4. Merge Sort: Time complexity is O(n log n) for all cases and space complexity is O(n).
5. Quick Sort: Time complexity is O(n log n) average case and space complexity is O(log n).
