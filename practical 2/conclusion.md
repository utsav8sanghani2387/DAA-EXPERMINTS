In this practical, we learned about searching techniques using Linear Search and Binary Search. We understood that Linear Search checks elements one by one from start to end, while Binary Search works on sorted data by repeatedly cutting the search area in half.

Time and Space Complexity:
1. Linear Search: Time complexity is O(n) worst case and space complexity is O(1).
2. Binary Search: Time complexity is O(log n) worst case and space complexity is O(1).
