In this practical, we learned how to find the Minimum Spanning Tree (MST) of a connected, undirected weighted graph using Prim's algorithm. We understood how Prim's algorithm adopts a greedy approach by starting from an arbitrary root vertex and progressively adding the minimum-weight edge connecting the growing tree to an unvisited vertex until all vertices are included.

Time and Space Complexity:
- Time Complexity: O(V^2) using an adjacency matrix, where V is the number of vertices.
- Space Complexity: O(V) for storing the visited/selected array and tree vertices.
