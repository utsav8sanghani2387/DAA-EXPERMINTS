In this practical, we learned how to calculate the factorial of a given number using iterative and recursive approaches. The iterative method uses a loop to multiply numbers step by step, while the recursive method calls the function repeatedly until it reaches the base case.

Time and Space Complexity:
1. Iterative Method: Time complexity is O(n) and space complexity is O(1).
2. Recursive Method: Time complexity is O(n) and space complexity is O(n) due to the recursive call stack.
