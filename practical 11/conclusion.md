In this practical, we learned how to find the shortest paths between all pairs of vertices in a weighted graph using the Floyd-Warshall algorithm. We understood how dynamic programming systematically considers each vertex as an intermediate node to update the shortest distance matrix, efficiently solving the all-pairs shortest path problem.

Time and Space Complexity:
- Time Complexity: O(V^3) for all cases (Best, Average, and Worst), where V is the number of vertices.
- Space Complexity: O(V^2) for maintaining the distance and cost matrix.
