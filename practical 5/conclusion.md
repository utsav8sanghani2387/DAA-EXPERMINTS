In this practical, we learned how to solve the 0/1 Knapsack problem using dynamic programming. We understood how using a table to store solutions of smaller subproblems helps us find the maximum profit without repeating calculations.

Time and Space Complexity:
- Time Complexity: O(n * W) where n is the number of items and W is the knapsack capacity.
- Space Complexity: O(n * W) for storing the dynamic programming table.
